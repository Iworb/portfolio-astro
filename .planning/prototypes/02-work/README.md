## Page: Work

### Surface
**Explore.** This is a curated project index: visitors browse a deliberately small set of relevant systems and decide which case study deserves their attention.

### Composition
- One lead case establishes a clear entry point without repeating the home page’s hero.
- Three supporting projects use unequal visual information: project type, a concise truth-based description, technologies, and an abstract project signal—not fake screenshots.
- Filters work across Industrial, Retail and Platform. They are useful because the project set spans these real contexts; they collapse cleanly on mobile.
- Case-study interactions intentionally state that the detailed case template is the next page to design. No unbuilt routes are implied as finished.

### Content boundary
All project descriptions and technologies are drawn from the current English project data. Detailed roles, constraints, outcomes and metrics are intentionally absent until confirmed.

### Slop self-audit
**Score: 0/10.** No tech-gradient or default-indigo palette; no equal feature-tile grid; no invented metrics or fake dashboard. The **Explore** surface uses a primary case plus browseable catalogue, which matches the visitor task. Manrope with DM Mono is carried from the approved home prototype.
