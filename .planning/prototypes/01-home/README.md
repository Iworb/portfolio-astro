## Page: Home

### Surface
**Decide / Learn.** The page makes one professional proposition, proves it with selected work and practice signals, then leads to résumé download or contact.

### Scope deliberately included
- Positioning and availability in the first viewport.
- Primary résumé download and secondary contact action.
- One featured case plus two compact project signals.
- A short professional-practice statement, not a duplicate of the Experience page.
- Desktop 12-column bento composition and intentional mobile stacking.
- Light/dark themes, contact-dialog state, hover states and reduced-motion handling.

### Not a final site implementation
This is a standalone prototype. Navigation targets communicate future page intent; it does not change the Astro application.

### Slop self-audit
**Score: 0/10.** The page uses a committed Decide / Learn composition, an intentional Manrope/DM Mono type system, real project content and one asymmetrically weighted featured case. No generic gradients, equal-weight feature tiles, unearned glass/blur, invented stats or centered-template composition were used.
