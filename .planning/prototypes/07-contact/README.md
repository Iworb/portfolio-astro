## Page: Contact

### Surface
**Operate.** The only task is initiating a conversation, so the primary action is a direct email—not a decorative form that needs infrastructure.

### Composition
- clear direct-email hero and working copy-to-clipboard interaction;
- mailto link with a pre-filled portfolio-enquiry subject;
- LinkedIn as secondary professional route;
- phone, location/work authorization and CV only as practical support;
- no form, fake availability calendar or generic sales copy.

### Slop self-audit
**Score: 0/10.** The page prioritizes an actual action, uses no decorative stat or contact-form theatre, and keeps secondary details subordinate to email.

### Verification note
Clipboard copying is implemented with a fallback that exposes the email address when the browser denies clipboard access.
