HELIX

A monitoring platform for surface and underground mining operations. The case is about a frontend architecture that lets a complex platform evolve without forcing every application to move in lockstep.

RoleLead frontend developer & architect
FocusMicroapps · shared library · migrations
MONITORING TOPOLOGY / ABSTRACT

The brief

01 / Context
Product

Monitoring for environments where location and state matter.

HELIX comprises applications for configuring the platform and applications that bring operational data to end users. It is used in both open-pit and underground mining.

Architectural pressure

Many applications had to remain independently developable, deployable and gradually upgradeable.

The answer was not one large frontend. It was a system of microapps with a common shell and shared capabilities.

Architecture, in use

02 / System

Each application is served from its own Docker container on a child route. An orchestrator resolves the route, while a shell loads shared functions and styles.
