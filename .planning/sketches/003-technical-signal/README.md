## Variant: Technical Signal

### Design stance
A command-like portfolio for a frontend architect: precise, dark-by-default and structurally explicit without pretending to be an IDE.

### Key choices
- Layout: persistent desktop rail + work surface; rail becomes horizontal navigation on mobile.
- Typography: Space Grotesk with IBM Plex Mono metadata.
- Color: graphite, technical grid lines and a single signal-green action color.
- Interaction: display mode, rail state changes, resume download and contact feedback.

### Trade-offs
- Strong at: technical credibility and visual distinctiveness.
- Weak at: most assertive/least neutral visual language of the three.

### Best for
Technical product organisations and complex B2B / industrial environments.
