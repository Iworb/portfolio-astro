## Variant: Bento CV First

### Design stance
A modular, high-density personal dashboard where the résumé download is visible twice without becoming salesy.

### Key choices
- Layout: asymmetric 12-column bento grid that becomes a meaningful vertical order on mobile.
- Typography: compact Manrope with mono labels for a calm technical rhythm.
- Color: neutral surfaces, one acid-lime action color, optional dark mode.
- Interaction: theme switch, PDF download, contact feedback state.

### Trade-offs
- Strong at: fast scanning of skills, availability and key work.
- Weak at: telling a deep case-study narrative.

### Best for
Recruiters and clients who need a confident overview in under a minute.
